# Contributing

This is a personal portfolio project maintained by Leonardo Ippolito. **Pull requests from outside contributors are not accepted** and the repository is configured to restrict pull requests to collaborators.

You are welcome to:

- open an issue with feedback, questions or a bug report;
- fork the project and use it under the [MIT license](LICENSE), keeping the copyright notice.

The owner's own workflow (every change through a pull request with a record) is described in [docs/standards/pull-requests.md](docs/standards/pull-requests.md).
