# Example automations

Automations documented to the full standard but **not built**: worked examples of how a spec reads for a case that is real in many revenue teams but too specific to build on Fernway's data. `tools/check_automations.py` skips this folder; nothing here runs.

| Example | Why it is here |
|---|---|
| [`multi-year-contract-split/`](multi-year-contract-split/SPEC.md) | One deal holding several contract years distorts renewal value and blocks provisioning. Shows a CRM-correction automation with idempotent clones, guards and a values rule |
