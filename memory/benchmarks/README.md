# Internal benchmarks

Baselines of Fernway's own metrics over time, so the agent can say "higher than the usual" with a period behind it.

## Format

One file per metric: a table of period, value, source table and the date it was measured. The agent cites the period when it compares.

## When it is updated

After each full month, from gold. External benchmarks are not here; they are in the `benchmarks` context document.

No baseline is recorded yet beyond what each metrics document states.
