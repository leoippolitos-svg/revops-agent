# Decisions

Deliberate decisions the agent treats as final. One file per decision.

## Format

Front matter: `date`, `status` (active, revised, revoked), `decided_by` (a role), `supersedes` (optional). Sections: Decision, Why, What it changes for the agent, Where the detail is.
