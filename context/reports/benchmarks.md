# External benchmarks

## Purpose

Market reference values the agent may put next to a Fernway number, always labelled as external. The agent reads it only when a question asks "is that good?" or "how do we compare?". Internal history is not here: it is in each metrics document. RevOps owns it and reviews it once a year; a value without a source and a year is removed.

## How the agent uses them

- Show the internal number first, then the benchmark, with its source and year: "our win rate is 42%; the reference range is 20% to 30% (source, year)".
- Never use a benchmark as a target. Targets are in [[doc:okrs]].
- If no benchmark matches the exact metric and segment, say there is none rather than stretching a near one.
- **Status draft:** the values below are fictional placeholders for the fictional company. Replace each with a sourced figure before using this repository for real.
