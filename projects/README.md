# Projects

One folder per line of work that spans more than one session. The index is in [WORKSPACE.md](../WORKSPACE.md).

Every project folder has two files:

- `README.md`: what it is, where it runs, how to run it, who owns it, where its rules are. Short and current.
- `CONTEXT.md`: the session history, newest first, one digest per session in the format of the `session-closing` context document.

Copy `_template/` to start. A project that only reads a document or holds a one-off answer still gets a folder when the work is worth finding later.
