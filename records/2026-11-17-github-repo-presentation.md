# The repository page on GitHub presents the project

## What was done
- Set the GitHub "About" box: a one-line description, 15 topics and the portfolio site as the website.
- Added `docs/img/social-preview.png` (1280×640). This is the image shown when someone shares the repository link. Uploading it is a manual step in Settings → General → Social preview.
- Published release `v1.0.0` as a milestone for the complete portfolio.

## Why
The repository is linked from the owner's portfolio site and from job applications. A visitor saw an empty sidebar with "No description, website, or topics provided".

## Result or decision
The repository has a description, topics, a link to the site and a first release. The numbers on the preview image (18 gold models, 32 skills, 24 ADRs, 587 tests) are the ones in the README on this date.

## Rules and context changed
None.

## Follow-ups
Regenerate the preview image if those numbers change a lot.
