# Remove the Credits section from the README

## What was done
Removed the "Credits" section from `README.md` and the matching words in `docs/standards/skills.md` that required crediting sources there.

## Why
The owner decided the section adds nothing for a reader of the portfolio. The standard had to change with it, so the repository does not ask for something its own README no longer has.

## Result or decision
- The rule that third-party skills and code are never copied into the repo stays, in `CLAUDE.md` and `docs/standards/skills.md`. Only the duty to list sources in the README is gone.
- No code or check depended on the section.
