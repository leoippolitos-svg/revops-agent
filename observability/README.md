# Observability

The agent loop writes one JSON line per question to `observability/logs/agent.jsonl` (gitignored), with the intent, tier, tools called, model calls, tokens and latency, and never the question, an answer or a row. Each line also has the routing step (`via`), cache write and read tokens, whether the classifier ran, and `cost_usd`, estimated from the price table in `agent/tools/README.md`; it is `null` while a model's price is unknown, never zero. Logs per agent question: intent, tools called, tokens, cost, latency. A weekly summary shows cost per intent and the slowest questions. Alerts go through `observability/notify.py` (ADR-0020): built by code, one thread per item, written to `logs/slack-<date>.md` as the simulated channel. Job health from the run catalog collector is in `logs/job-health.json`.
